Clipify — portable video downloader
===================================

No installation is needed. Run “Clipify” from this folder.

1. Paste a YouTube link.
2. Optionally enter the start and/or end time:
   90       — seconds
   01:30    — minutes and seconds
   1:02:03  — hours, minutes, and seconds
3. Choose a folder, or leave it blank to save next to the app.
4. Select “Download video”.

Use “Frame-accurate cut” when exact boundaries matter. Processing will take
longer and use more CPU.

English is selected on first launch. Use EN/RU in the top-right corner to
change the interface language.

All required components are included. An internet connection is only needed
to retrieve video information and download the file.

If a system or network error occurs, details are saved to clipify.log next to
the app and a short message appears in the interface.

If a file with the same name already exists, Clipify saves a numbered copy and
keeps the previous download unchanged.


Русский
-------

Установка не нужна. Запустите «Clipify» из этой папки.

1. Вставьте ссылку YouTube.
2. При необходимости укажите начало и/или конец:
   90       — секунды
   01:30    — минуты и секунды
   1:02:03  — часы, минуты и секунды
3. Выберите папку или оставьте поле пустым, чтобы сохранить рядом с программой.
4. Нажмите «Скачать видео».

Включите «Точные границы кадра», если важен точный момент обрезки. Обработка
займёт больше времени и сильнее нагрузит процессор.

При первом запуске выбран английский язык. Для смены языка используйте EN/RU
в правом верхнем углу.

Все необходимые компоненты уже включены. Интернет требуется только для
получения сведений о видео и самой загрузки.

При системном или сетевом сбое подробности записываются в clipify.log рядом
с приложением, а краткое сообщение появляется в интерфейсе.

Если файл с тем же именем уже существует, Clipify сохранит копию с номером и
не изменит предыдущую загрузку.
